# Garry's powered plug sign

Independent 64x96 wall-mounted neon plug. Choose it in the Builder's Garry's Electronics or Electric filter to place a real four-charge absorbable source. It can be moved separately from the building panels. Frames `00`-`01` are powered, `02`-`05` pulse while absorbing, and `06`-`07` are drained.

`source.png` is the generated master. Run `python scripts/build_plug_sign_frames.py` to regenerate the eight frames and `preview.png`. The plug is not baked into the Garry's Electronics facade and is not placed in Level 1 by this pack.
