# Level 1 blue rooftop concept

This is a visual layout mockup, not a replacement for `src_scroll/levels/level1.json`. The two PNGs in this folder show a clean panorama and an annotated seven-beat route. The composition uses only the existing Level 1 night-city-rail background, blue rooftop tiles, the hero scale reference, and powered/electric props already in the repository. It adds no new gameplay assets.

The route rises twice in 64-pixel steps, drops 96 pixels, then rises twice more before the exit. Each illustrated gap is 64 pixels. The beats are start, power source, climb, drop, switch/fence, final rise, and exit. The fence, switches, and gate are visual placements; actual charge wiring, collision, jump reach, and gate conditions must be playtested before transferring this arrangement into the Builder. The mockup does not move the live Level 1 gate or alter any level file.

Source composition script: `outputs/build_level1_blue_mockup.py` in the Chief task workspace.
