# BOOKS neon wall sign

Independent 160×96 powered wall prop, placeable from the Builder's Electric filter. `00`–`01` show the powered sign, `02`–`05` the absorb pulse, and `06`–`07` the drained sign. It becomes a real absorbable source with the usual four charge when placed, rather than static facade decoration.

`source.png` is the generated master. Run `scripts/build_book_sign_frames.py` to regenerate the eight frames and contact-sheet `preview.png`. The sign is not baked into the Bry's Library building panels and is not placed in Level 1 by this pack.
